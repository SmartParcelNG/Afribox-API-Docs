Afribox backend API (SmartParcel). All endpoints accept JSON over POST (unless noted). Authentication is via an `apikey` in the request body: an Application API key, a Business public key, or a Business secret key. The HTTP status is always 200; the outcome is reported in the body via `statuscode` (`00` = success) and `statusmessage`.
